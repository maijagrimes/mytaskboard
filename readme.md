myTaskboard 
https://mytaskboard.neocities.org/ 

A Kanban-style task board where users can manage work visually.

Tech Stack: 

    React + Vite - Build tools
    Supabase - Database & user authentication
    Git - Version control
    Github + Neocities - CI/CD Pipeline & live hosting
